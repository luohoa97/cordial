# Cordial 0.19.0 — private servers, plugins without restarting

## Private servers

Two ways of joining a private server did nothing before, and both now join
it:

- **Opening a private server on the Roblox website.** The link carries the
  server's access code, and Cordial used to refuse the whole link rather than
  drop the code and put you in a public server instead. It now passes the
  code on.
- **Pressing Join on a private server in a game's Servers list.**

Confirmed joining a real private server.

## The web view closes when you join a game

Joining a game from a page Roblox opens (a game's Servers list, for one) now
closes that page instead of leaving it on top of the game.

## Plugins apply without restarting

Installing, enabling, disabling or updating a plugin now takes effect in any
Cordial that is already running on that profile, within about a second. A
plugin that is updated gets only the permissions its new version asks for.

## Smaller fixes

- The first click on a text box no longer puts the typing cursor in the
  wrong place. Home's search bar opens a panel that animates to its final
  size, and the cursor used to follow the animation; it now waits for it
  to finish.
- Leaving fullscreen no longer leaves the title bar missing until the menu
  is opened. This one is not confirmed: it could not be reproduced on a
  test machine.
- Two Cordial processes installing a Roblox build at once can no longer
  corrupt it.

## What is still broken

**The signed-in startup freeze is not fixed.** It has been much rarer in
testing since 0.18.0 — about one launch in twelve, where it used to be
nearly half — but the cause is still not found.

**The screen can still grey out when a text box takes focus**
([#53](https://github.com/luohoa97/cordial/issues/53)). If you hit this on
Hyprland, the issue asks for a trace that would help.

**A game's `DF` FastFlags, such as `DFIntTaskSchedulerTargetFps`, can reset
partway through a session**, because the Roblox client refreshes them from
Roblox's servers on its own schedule.

**Some games show the mobile (touch) interface.**

Still open from earlier releases: a crash after a second launch
([#44](https://github.com/luohoa97/cordial/issues/44)), a freeze and crash
leaving fullscreen ([#39](https://github.com/luohoa97/cordial/issues/39)), a
crash on first touch with a touchscreen
([#36](https://github.com/luohoa97/cordial/issues/36)), a crash on launch on
some machines ([#35](https://github.com/luohoa97/cordial/issues/35)), no
window on COSMIC, KWin or wlroots compositors
([#38](https://github.com/luohoa97/cordial/issues/38)), a hang on exit
([#52](https://github.com/luohoa97/cordial/issues/52)), pointer drift during
camera drags on Hyprland
([#56](https://github.com/luohoa97/cordial/issues/56)), and a rare crash just
after startup ([#63](https://github.com/luohoa97/cordial/issues/63)). ARM64
builds are still untested on real hardware. VR is not supported.
