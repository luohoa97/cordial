# Cordial 0.34.1: loads Roblox 2.746

## What you can do now

- **Roblox 2.746.0.1266 starts.** On 0.34.0 it stopped before any window
  appeared, with `LOAD FAILED ... cannot locate symbol "AImageReader_delete"`.
  That build asks for nine Android video-decoding functions Cordial did not
  have. Cordial now answers them by saying it does not support them, so the
  engine loads and reaches its first frame.

## What is still broken

**Video that Roblox decodes through the Android image reader may not play.**
Cordial tells the engine that path is unsupported. We have not yet reached a
place in a game that uses it, so we do not know whether Roblox falls back or
shows nothing. If a video stays blank, the log will have a line starting
`[media] AImageReader_newWithUsage`; please include it in a report.

The rest of the list in the
[0.34.0 notes](https://github.com/luohoa97/cordial/releases/tag/v0.34.0) still
applies.
