# Cordial 0.34.2: loads Roblox 2.748

## What you can do now

- **Roblox 2.748.0.1527 starts.** On 0.34.1 it stopped before any window
  appeared, with `LOAD FAILED ... cannot locate symbol "AMediaCodec_createCodecByName"`.
  Cordial now answers that call by saying it has no media codec, so the engine
  loads and reaches its first frame.

## What is still broken

**Video that Roblox decodes through an Android media codec may not play.**
Cordial tells the engine no codec is available. We have not yet reached a place
in a game that uses it, so we do not know whether Roblox falls back or shows
nothing. If a video stays blank, the log will have a line starting
`[media] AMediaCodec_createCodecByName`; please include it in a report.

The rest of the list in the
[0.34.0 notes](https://github.com/luohoa97/cordial/releases/tag/v0.34.0) still
applies.
