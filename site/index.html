Open-source Roblox for Linux

Cordial runs Roblox natively. No Wine, no emulator, no Android container.

Install Flatpak · x86-64 · needs a Vulkan GPU

Cordial runs Roblox’s official Android build natively on your machine — no Wine, no emulator, no Android container. It is GPL-3.0 and fully auditable: every line of what runs on your machine is published, which is the part most Linux Roblox clients cannot say.

Cordial fetches the Roblox build for you. It ships no Roblox code and never will, but first run has one button — Download Roblox — and that is the whole of it. If Sober has already downloaded the same build, Cordial uses that copy where it lies rather than fetching it again; otherwise it downloads from a public APK mirror and verifies that Roblox's own signing certificate signed those exact bytes before installing. You can still point it at an APK yourself.

How Cordial compares to Sober, mocktail and Waydroid — including where they are better.

What you get

Profiles

Separate sign-ins, settings and caches. Each one is locked to a single running instance, so two windows can’t corrupt each other’s data.

Plugins

Discord presence, custom textures and sounds, and more. A plugin never gets a socket or a file — it asks, and Cordial does it.

Settings that tell you what happened

Every Roblox flag you set, and every conflict between them, printed at startup. No config file with a “don’t edit this by hand” warning at the top.

Cordial vs Sober vs Waydroid

Written to be useful rather than flattering. Sober is a good client and is what most people on Linux use today; if you want the smoothest path and do not care about source availability, use Sober.

Cordial
SourceOpen, GPL-3.0. Every line auditable.
HowNative. AOSP bionic linker, a bionic/glibc shim, a JNI VM in place of Android’s.
ExtensibleYes — a plugin API with brokered capabilities. No plugin gets a socket or a file descriptor.
Gets the buildYou supply it, or it reads Sober’s copy.
MaturityYounger, and rougher. See the status page before installing.
Sober
SourceNot available. vinegarhq/sober is an issue tracker; the client itself is not published.
HowNative, by its own account. Architecture not described in detail.
ExtensibleFastFlags, no plugin API.
Gets the buildDownloads it for you. This is the thing it does that Cordial does not.
MaturityMature and widely used.
Waydroid
SourceOpen, GPL-3.0.
HowA full Android container. Roblox runs inside Android, which runs on your kernel.
ExtensibleNot for Roblox specifically.
Gets the buildYou install the APK inside Android.
MaturityMature, but it is general Android infrastructure and not a Roblox client.

The short version: Waydroid runs Android and Roblox happens to be in it. Sober runs Roblox and does not show you how. Cordial runs Roblox and shows you all of it.

Install

flatpak remote-add --if-not-exists --no-gpg-verify \
    cordial https://luohoa97.github.io/cordial/repo

flatpak install cordial io.github.luohoa97.Cordial

Then launch it, sign in, and press play. Nothing from Roblox is bundled or redistributed — Cordial downloads the official build to your machine and never re-serves it.

One thing to know first: if your account uses a passkey for two-factor, you cannot sign in yet. That is a missing piece in WebKitGTK rather than something Cordial can work around. Full status on GitHub.
